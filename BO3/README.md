# Black Ops 3

| Mod | What it does |
| --- | --- |
| [More Players](more-players/README.md) | Up to 8 players in one zombies match, with score rows and revive icons for players 5 to 8. |

It works on the BOIII client: hosted with 7 bots on all 14 maps. It has not been tried with
real people in slots 5 to 8, and it has not been built for the Steam game or the Workshop.
The mod's README says what was run and how to build it.

There is no download on the releases page yet.
