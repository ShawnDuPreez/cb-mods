More Players - 8-player zombies for Infinite Warfare (iw7-mod)
==============================================================

Everyone who plays needs this, not only the host.

Install
-------
1. Open your game folder, the one that holds iw7-mod.exe.
   In the CB Servers launcher: Infinite Warfare > Browse Local Files.
2. Extract this zip into that folder.
   It adds four files inside the iw7-mod folder that is already there.
   Nothing is replaced.
3. Start the game.

Do not use the launcher's Mods > Import for this zip, and do not pick anything
in the game's Mods menu. This mod is always on once the files are in place.

Play
----
Zombies > Custom Game. The lobby now holds 8. Friends join as usual.

Remove
------
Delete these from the game folder:

  iw7-mod\custom_scripts\cp\more_players.gsc
  iw7-mod\custom_scripts\cp\scoreboard.gsc
  iw7-mod\ui_scripts\MorePlayers
  iw7-mod\ui_scripts\ZombiesPlayers
  iw7-mod\more-players-readme.txt
