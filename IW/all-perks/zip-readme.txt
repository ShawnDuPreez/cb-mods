All Perks - start zombies with every perk (Infinite Warfare, iw7-mod)
====================================================================

Only the host needs this. Friends who join need nothing.

Install
-------
1. Open your game folder, the one that holds iw7-mod.exe.
   In the CB Servers launcher: Infinite Warfare > Browse Local Files.
2. Extract this zip into that folder.
   It adds one file inside the iw7-mod folder that is already there.
   Nothing is replaced.
3. Start the game and host a zombies match.

Do not use the launcher's Mods > Import for this zip. This form is always on
once the file is in place, and it works beside any mod you pick in the game's
Mods menu.

Play
----
About 10 seconds into a match every player is handed all of the map's perks.
They come back after you are revived or return from the afterlife arcade.

Off for one match
-----------------
In the console, before the match starts:   set all_perks 0
(set all_perks 1 turns it back on. It is also on again after a game restart.)

Remove
------
Delete this from the game folder:

  iw7-mod\custom_scripts\cp\all_perks.gsc
  iw7-mod\all-perks-readme.txt
