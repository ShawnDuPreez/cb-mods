Perk Limit - the host's menu script (Infinite Warfare, iw7-mod)
===============================================================

This goes with the PERK_LIMIT mod (perk_limit.zip). Only the player who hosts
needs it. Friends who join need only the mod.

Why: right after you pick a mod in the game's Mods menu, the game does not run
anything from that mod until a match has been played. This small file sits in
the game's own iw7-mod folder instead, so the PERK LIMIT row is there as soon
as you pick the mod. It shows nothing while any other mod, or no mod, is
loaded.

Install
-------
1. Open your game folder, the one that holds iw7-mod.exe.
   In the CB Servers launcher: Infinite Warfare > Browse Local Files.
2. Extract this zip into that folder.
   It adds one file inside the iw7-mod folder that is already there.
3. Start the game, pick PERK_LIMIT in the Mods menu, then
   Zombies > Custom Game > MATCH SETTINGS.

Remove
------
Delete these from the game folder:

  iw7-mod\ui_scripts\PerkLimit
  iw7-mod\perk-limit-menu-readme.txt
