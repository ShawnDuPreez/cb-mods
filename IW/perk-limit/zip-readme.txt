Perk Limit - choose how many perks a player can hold (Infinite Warfare, iw7-mod)
==============================================================================

Only the host needs this. Friends who join need nothing.

Install
-------
1. Open your game folder, the one that holds iw7-mod.exe.
   In the CB Servers launcher: Infinite Warfare > Browse Local Files.
2. Extract this zip into that folder.
   It adds two files inside the iw7-mod folder that is already there.
   Nothing is replaced.
3. Start the game.

Do not use the launcher's Mods > Import for this zip. This form is always on
once the files are in place, and it works beside any mod you pick in the
game's Mods menu.

Play
----
Zombies > Custom Game > MATCH SETTINGS. Under OPEN TO FRIENDS there is a new
row, PERK LIMIT. Use left and right to choose 1 to 11 perks or No limit. The
game's own limit is 5, and that is what you get until you change it. The
choice lasts until you close the game.

In a Solo Match there is no Match Settings; the lobby has its own PERK LIMIT
button there, last in the list.

Remove
------
Delete these from the game folder:

  iw7-mod\custom_scripts\cp\perk_limit.gsc
  iw7-mod\ui_scripts\PerkLimit
  iw7-mod\perk-limit-readme.txt
